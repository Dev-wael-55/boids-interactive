# 🐦 Boids Interactive Simulation

محاكاة تفاعلية لأسراب الطيور (Boids) باستخدام Python و Pygame، مع تحكم مباشر بالماوس ولوحة المفاتيح.

---

## 🎮 التحكم

| الإجراء | التأثير |
|---------|---------|
| **SPACE** (اضغط مع الاستمرار) | طرد الطيور وتشتيتها بعيداً |
| **Click بالماوس** أو **LSHIFT** أو **ENTER** | جذب الطيور وتجميعها حول المؤشر |
| **R** | إعادة تعيين الطيور في مواضع جديدة |
| **ESC** | الخروج من البرنامج |

---

## ✨ المميزات

- 🐦 **280 طائراً** تتحرك بذكاء وفق قواعد Boids الكلاسيكية (Separation, Alignment, Cohesion)
- 🖱️ **تفاعل مباشر** مع مؤشر الماوس بحركة انسيابية
- 🎯 **ثلاثة أنماط** للتفاعل: هادئ (Idle)، جذب (Attract)، طرد (Repel)
- ⭕ **دوائر تفاعلية** توضح منطقة التأثير بلون يتغير حسب الحالة
- 🔄 **حواف لانهائية** — الطيور تظهر من الجهة المقابلة عند الخروج
- 🎨 **رسم ناعم** للطيور بأسلوب أسهم دقيقة
- 🖥️ **وضع ملء الشاشة** بدون إطار بدقة 1080×1920

## ⚙️ كيفية العمل

تعتمد المحاكاة على **خوارزمية Boids** التي وضعها Craig Reynolds عام 1987، والتي تحاكي سلوك أسراب الطيور من خلال ثلاث قواعد بسيطة:

1. **Separation (الانفصال):** تجنّب التزاحم مع الجيران القريبين
2. **Alignment (المحاذاة):** التوجه بنفس اتجاه الجيران القريبين
3. **Cohesion (التماسك):** البقاء قريباً من مركز المجموعة

بالإضافة إلى ذلك، يتفاعل كل طائر مع مؤشر الماوس حسب الوضع الحالي:

- **وضع الطرد:** يهرب الطائر بعيداً عن المؤشر بقوة تتناسب عكسياً مع المسافة
- **وضع الجذب:** ينجذب الطائر نحو المؤشر مع دوران دائري انسيابي عند الوصول
